Support

Rowwise for iPhone · version 1.0 · answered by email, usually within a couple of days.

There is no account to reset. Rowwise has no server and no sign-in, so most support questions are really questions about how the app behaves. The ones below are answered here rather than behind a ticket on purpose.

I bought Rowwise Pro and it is asking me again

The purchase is tied to your Apple Account, not to the app. Open Settings in Rowwise and tap Restore purchase — the row says "Same Apple Account, new phone, or after a reinstall" because that is the rule. If you bought it on a different Apple Account, restore will not find it; the receipt lives wherever the original one does.

What is free, and what is the one payment for?

Counting is free and stays free: unlimited projects, several counters per project, notes on any row, undo, haptics, targets. The one-time purchase of Rowwise Pro adds three things — a photograph on a row, the ZIP backup that carries those photographs, and the printable PDF project card. Nothing renews, and there is no subscription in this app.

Where does an export actually go?

Wherever you put it. Settings → Export (or backup / card beside one project) writes the file inside Rowwise and then opens the iOS share sheet, and you choose the destination — Files, Mail, a drive, nowhere. Rowwise keeps the five newest backup archives in its own storage so an export you lost track of can be re-shared, and prunes older ones. The app has no networking code, so it cannot send any of this anywhere by itself.

"Your saved rows could not be opened"

This appears when the file Rowwise writes to is there but no longer readable. The app deliberately does not open an empty library in that case, because your next tap would save over the only copy of your work. Instead it sets the bytes aside under a name that says what happened — rowwise-unreadable-YYYYMMDD-HHMM.json — and stops writing. Your route back is Settings → Import a backup, using a .zip Rowwise exported. If you need the set-aside file recovered rather than replaced, write to the address at the bottom and say which of the two messages you got; the file is still on your phone.

The backup will not import

Two different messages, two different causes. "That archive has no rowwise.json in it" means the file was not produced by Rowwise — pick the .zip from the Export row, not a file you re-zipped or renamed yourself. "That backup was written by a newer Rowwise" means exactly that: update the app first, then import.

I tapped undo — did it take my note with it?

No. Undo takes back one row on the counter and never touches a record. Notes and photographs belong to the row number, so if you undo to 45 and count back to 46, whatever you wrote on 46 is still there.

Can I photograph a row I counted earlier?

Yes. In Row by row, tap the row — that opens its record, where you can add or replace a photo and write or delete the note. The Photo at 46 button on the counter is only the shortcut for the row you are on.

Why is the App Store page in my language but the app is in English?

Version 1.0's interface is English-only; the store page has been translated ahead of the app so you can tell what it does before you buy it. That is stated in every language's description too, so nobody finds out at first launch. Other languages are on the list, and which one comes first is decided by what people actually ask for — the address below.

Does it work on a plane, or in a basement?

It always does. Rowwise has no server to reach, so there is no connection that can fail. The only thing that needs a network is the purchase itself.

Refunds

Purchases go through Apple and are governed by Apple's refund process: reportaproblem.apple.com. We cannot issue a refund from our side, and we never see your card details.
